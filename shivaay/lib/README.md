# Flutter App UI (GUI only)

A static, navigable Flutter interface inspired by the supplied mobile app reference. It includes welcome/onboarding, dashboard, tasks, notifications, profile, edit profile, settings, and a logout confirmation dialog. All displayed data is sample data. Buttons are visual/demo interactions only; authentication, networking, persistence, QR scanning, and task operations are not implemented.

## Open and run

1. Install Flutter and an Android emulator or connect a device.
2. Open this folder in Android Studio or VS Code.
3. In the project folder, run `flutter create --platforms android,ios,web .` once to generate platform runner folders.
4. Run `flutter pub get` and then `flutter run`.

The project contains `lib/main.dart` and `pubspec.yaml`; platform runners are generated by Flutter on the target machine.
